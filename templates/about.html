About CrediGuard Project

Credit Risk Monitoring & Prediction System.

Project Objective

CrediGuard is an integrated Credit Risk Monitoring & Prediction System built to demonstrate how Machine Learning classification algorithms can assist financial decision-support workflows.

The system combines complete CRUD (Create, Read, Update, Delete) operations for applicant financial profiles with a real-time Scikit-Learn Machine Learning inference pipeline (`RandomForestClassifier`), persistent SQLite storage, and dynamic analytical dashboards.

System Data Flow Architecture
Applicant Form Input
Form Input Validation
DTI Auto Calculation
Random Forest ML Model
Risk Category & Probabilities
SQLite Database Log
Interactive Dashboard
Technology Stack Breakdown
Backend & Database
  • Python 3.10+: Core application language
  • Flask Framework: Lightweight web server & routing
  • SQLite Database: Embedded relational data store
  • SQLAlchemy ORM: Object-Relational Mapping & cascade relationships
Machine Learning
  • Scikit-Learn: `RandomForestClassifier` ensemble pipeline
  • ColumnTransformer: Automated One-Hot Encoding for categorical features
  • Pandas & NumPy: Data processing & synthetic dataset generation
  • Joblib: Model pipeline serialization (`.pkl`)
Frontend & UI Components
  • HTML5 & CSS3: Clean layout, custom styling, dark navbar accents
  • Bootstrap 5: Responsive grid, form components, badges, modals, and alerts
  • Vanilla JavaScript: Real-time DTI calculator and DOM event handling
  • Chart.js: Dynamic executive dashboard & probability bar graphs
